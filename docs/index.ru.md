XBSL предназначен для работы с исходниками проектов **1С:Элемент**. Проект состоит из пар
файлов: `Имя.yaml` описывает элемент, а `Имя.xbsl` содержит код. XBSL проверяет исходники
до серверной компиляции при деплое. В состав инструментария входят движок на Python и расширение
VS Code на его основе.

## Что внутри

- **Линтер с автоисправлениями** – 280 правил в четырех тирах: структура yaml, соглашения
  по тексту и типографике, структура кода и семантика, проверяемая по данным технологии и
  самому проекту (плагин может добавить свои правила поверх).
- **LSP-сервер** – живая диагностика, переход к определению и автодополнение для любого
  редактора с поддержкой LSP.
- **Создание метаданных** – создание объектов, реквизитов, маршрутов и форм без ручного
  написания yaml.
- **Перевод проекта на английские написания** – словарь проекта, покрытие и проверка в CI.
  Остаток предлагает внешний переводчик, Yandex или Google.
- **Поиск по документации** – локальный полнотекстовый индекс, собранный из вашего
  дистрибутива 1С:Элемент.
- **MCP-сервер** – проверка исходников, поиск по документации и каждая операция создания
  метаданных. Эти инструменты доступны ИИ-агенту.
- **Веб-панель** – локальная страница с находками проекта: настройки правил по тирам, фильтры
  и открытие файла в редакторе.
- **[Расширение VS Code](https://github.com/keyfire/xbsl/blob/main/editors/vscode/README.md)**
  (издатель `keyfire`, идентификатор расширения `keyfire.xbsl`) – подсветка синтаксиса,
  диагностика по всему проекту, конструктор форм, дерево метаданных, панель документации
  1С:Элемента, отладка и кнопка деплоя – все на том же движке.

## Рядом

Для работы с проектами 1С также доступны следующие инструменты:

- **[Elemctl](https://docs.keyfire.ru/elemctl/ru/)** собирает приложение из исходников, загружает
  и применяет сборку, а также проверяет запуск стенда на новой версии. Команда *XBSL: деплой
  на стенд* расширения VS Code использует Elemctl.
- **[EDT-Bridge](https://docs.keyfire.ru/edt-bridge/ru/)** предоставляет MCP-доступ к 1С:EDT
  для платформы 1С:Предприятие. Через него агент читает конфигурацию, редактирует модули и формы,
  собирает расширения и выполняет отладку.

Данные о языке (ключевые слова, каталог типов stdlib, метамодель конфигурации) генерируются
из вашего дистрибутива 1С:Элемент и не поставляются с проектом – см.
[Данные о языке](/ru/start#данные-о-языке) в руководстве.

Не аффилировано с 1С. "1C:Element", "1C:Fresh" и связанные наименования – товарные знаки
соответствующих правообладателей – см.
[NOTICE](https://github.com/keyfire/xbsl/blob/main/NOTICE).
