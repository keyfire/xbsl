Руководство разложено по задачам. Короткая экскурсия – в [README](https://github.com/keyfire/xbsl/blob/main/README.ru.md). Каждая страница ниже подробно разбирает свою часть инструментария.

| Страница | Что там |

| [Правила](/ru/RULES) | полный перечень проверок с уровнями и областью |
| [Создание метаданных](/ru/scaffolding) | объекты, реквизиты, маршруты и формы движком; шаблоны кода |
| [Серверы и плагины](/ru/servers) | сервер LSP, сервер MCP, веб-панель, свои плагины |
| [Данные платформы](/ru/platform-data) | сгенерированные наборы, индекс документации, сравнение двух версий |
| [Перевод проекта](/ru/translation) | перевод исходников на английские написания: словарь, покрытие, проверка в CI |
| [Команды](/ru/CLI) | все команды и опции, собрано из самого инструмента |
| [Расширение VS Code](/ru/vscode) | редактор на том же движке: диагностики, дерево метаданных, деплой |
| [Визуальный конструктор](/ru/DESIGNER) | панель формы, палитра, панель свойств |
| [Панель документации](/ru/DOCS_PANEL) | справка платформы в редакторе: содержание, поиск, страница символа |
